# Code style guidelines
General (all modules): Java 21, Spring Boot 3, Lombok (`@RequiredArgsConstructor`, `@Slf4j`), 4-space indent, constructor injection, no wildcard imports in new files. Match surrounding code.

Banking module specifics (layer rules, naming, `BankingMessages`, logging levels) are in `rules/banking/code-style.md` and the per-layer files in `rules/banking/`.
